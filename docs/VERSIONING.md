# 版本规则

> **一句话**：三段式进位、什么算功能更新、**不发版就不要动版本号**。

---

## 1. 版本号形态

`主版本.次版本.修订号`（如 `0.1.0`），**只有软件行为变化才进位**，纯文档改动不动号。

- 载体：根 [CHANGELOG.md](../CHANGELOG.md) 的段标题 + git tag（`v` 前缀只属于 tag）。
- 文件名：`docs/release-notes/<版本号>.md`，**不带 `v`**。

## 2. 进位规则

| 变更 | 进位 |
|---|---|
| 新增补丁工具 / 新增一整层适配 | 主版本或次版本 |
| 适配新的电脑管家版本（特征码更新、新落点） | 次版本 |
| 修 bug、特征码微调、文档修正 | 修订号 |
| 纯文档 / 门面改动 | **不动号**（走 CHANGELOG `[未发布]`） |

## 3. 不发版的时候：不要动版本号

改动先记在 CHANGELOG 的 `[未发布]` 段；发版时才把 `[未发布]` 落成版本号段、
写 `docs/release-notes/<版本>.md`、打 tag。**没有发版动作，就不建版本号段、不打 tag。**
