遇到问题、想要新功能，到 [Issues](https://github.com/MVennn/XiaomiPcManagerPatch/issues/new/choose) 反馈 —— 请附 Windows 版本、机型、安装包版本号与脚本输出。

## 本版内容

**补丁**

- 新增 `xpm_patch.py` —— 安装包机型白名单补丁 + 运行时机型伪装。
- 新增 `padgate_patch.py` —— 平板镜像多显示器 / 独显拦截补丁。

**仓库**

- 新增 七段式 README 与 `docs/`（架构 / 工具清单 / 踩坑 / 调研 / 版本规则）。
- 新增 `check-secrets.py` / `check-docs.py` 守卫与 CI；Issue 表单三件套。
